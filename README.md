# 🦁 LIONADS Dashboard

Dashboard completo para mineração de ofertas, análise de anúncios, geração de copy, criativos, landing pages e tracking de performance.

## Como usar

Abra o arquivo `index.html` em qualquer navegador moderno.

```bash
# Ou sirva localmente:
npx serve .
# ou
python -m http.server 8080
```

## Seções

| Menu | Função |
|------|--------|
| 🔎 **Minerar** | Busca e descoberta de ofertas/nichos quentes |
| 🧠 **Analisar** | Métricas e análise de performance |
| 🧬 **Modelar** | Modelos de predição (ROAS, audiência) |
| 💎 **Ofertas** | Gestão de ofertas salvas |
| ✍️ **Copy** | Gerador de copy com IA |
| 🎬 **Criativos** | Biblioteca e geração de criativos |
| 🌐 **Landing Pages** | Gestão de LPs |
| 📊 **Tracker** | Acompanhamento de campanhas e ROAS |
| 📁 **Projetos** | Organização por projetos |
| ⭐ **Favoritos** | Itens marcados |
| 🕘 **Histórico** | Atividades recentes |
| ⚙️ **Configurações** | Conta, integrações e plano |

## Stack

- HTML + Tailwind CSS (CDN)
- JavaScript vanilla
- Tema dark com accent laranja/lion

Pronto para evoluir com backend real (APIs de ads, IA, tracking).
